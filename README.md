# Prototype app demonstrating android's fade-through animation

### You can view the implemented animation [here](https://github.com/material-components/material-components-android/blob/master/docs/theming/Motion.md#shared-axis) on material design github resource (first number).

To run the app, type in terminal `npm run start`

The fade-through animation is contained in [src/app/app.component.ts](src/app/app.component.ts#L16)

The animation is done with exact timings and easings collected throughough the internet. If you find any discrepancies with the original animation, please point it out and fill in an issue.
